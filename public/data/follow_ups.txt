# 꼬리질문 규칙 — 일반 텍스트 파일입니다. JSON 문법을 몰라도 이 파일만 고치면 됩니다.
#
# 한 줄에 규칙 하나. '#'으로 시작하는 줄과 빈 줄은 무시됩니다.
#
# 형식:
#   원래질문id | 감지할단어1,감지할단어2,... | 다음질문id | 우선순위(선택) | 트리거타입(선택)
#
# - 원래질문id / 다음질문id : data/questions.json에 있는 질문의 "id" 값
# - 감지할단어 : 사용자의 답변(음성 인식 텍스트)에 이 단어들 중 하나라도 포함되면 발동
#   (쉼표로 여러 개 나열 가능, 공백은 자동으로 정리됩니다)
# - 우선순위 : 숫자가 클수록 먼저 검사합니다. 안 적으면 0으로 취급합니다.
#   (같은 질문에 여러 규칙이 동시에 맞을 때만 의미가 있습니다)
# - 트리거타입(선택, 안 적으면 keyword) : keyword(기본, 감지할단어 중 하나라도 있으면 발동) /
#   missing_keyword(감지할단어가 전부 없으면 발동) / answer_length(감지할단어 무시, 답변 시간이
#   권장 시간의 절반 미만이면 발동) / missing_number(감지할단어 무시, 답변에 숫자·성과 표현이
#   하나도 없으면 발동 — lib/feedback.ts의 hasNumberOrResult 재사용)
#
# 예) 아래 줄은 "strength" 질문에 답할 때, 답변에 "チーム" 또는 "協力"이 나오면
#     "role"이라는 질문(data/questions.json에 있는 id)을 이어서 묻는다는 뜻입니다.
#
