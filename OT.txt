[프로젝트 기획안]

프로젝트명: Voice Interview JP (일본 IT 취업 대비 제로-비용 음성 모의 면접 트레이너)

---

1. 기획 목적 및 핵심 방향

* 목적: 일본 IT 기업 취업을 준비하는 한국인 지원자를 위한 완전 무료(0원) 웹 기반 음성 모의 면접 연습 플랫폼 구축.
* 핵심 방향:
* LLM API(OpenAI, Gemini 등)를 완전히 배제하여 추가 요금 발생 가능성을 100% 차단.
* 브라우저 표준 Web Speech API를 활용해 질문 음성 출력(TTS) 및 실시간 답변 자동 타이핑(STT) 구현.
* 사전 정의된 질문 풀과 사용자 커스텀 질문을 Supabase DB로 동적 관리하고 답변 로그를 영구 저장.



---

2. 기술 스택 및 인프라 구성 (100% 무료 티어)

* 프런트엔드 & 배포: Next.js + Vercel (Hobby Free Plan)
* Vercel 무료 티어를 통한 간편한 CI/CD 및 웹 호스팅.


* 백엔드 & 데이터베이스: Supabase (Free Tier)
* PostgreSQL Database: 질문 데이터셋(카테고리별/난이도별), 사용자 맞춤 질문, 모의 면접 세션 로그 저장.
* Supabase Storage: 음성 녹음 파일(.webm) 저장 (필요 시 활용, 무료 1GB 제공).


* 음성 처리 엔진: Web Speech API (Client-side)
* 음성 인식 (STT): `SpeechRecognition` (일본어 `ja-JP` 실시간 음성 타이핑).
* 음성 합성 (TTS): `SpeechSynthesis` (일본어 네이티브 질문 음성 낭독).


* 과금 정책 명시:
* LLM API를 일체 사용하지 않으므로 토큰 사용량에 따른 과금 위험이 전혀 없음. (※ 향후 AI 첨삭 기능 도입 시 요금이 추가될 가능성이 있으므로 본 버전에서는 제외)



---

3. 주요 기능 정의

* 1. 동적 질문 출제 시스템 (Supabase 연동)


* 카테고리별 랜덤 출제: 기본 인성(자기PR/지원동기), 기술 프로젝트(경험/에러 해결), 컬처핏, 역질문 등에서 세트 조합 생성.
* 커스텀 질문 관리: 사용자가 목표 기업의 채용 공고(JD)나 본인 이력서에 맞춘 질문을 직접 추가/수정/삭제.
* 질문 한국어 번역 토글 및 다시 듣기(TTS) 기능.


* 2. 실시간 일본어 음성 타이핑 & 인터페이스


* 마이크 입력 시작 시 사용자가 말하는 일본어를 화면 텍스트 입력창에 실시간 스트리밍 타이핑.
* 발음 정확도 자가 점검: 음성 인식이 정확하게 되었는지 눈으로 즉시 확인.
* 제한 시간 타이머(1분/2분) 및 답변 텍스트 수동 보정 기능.


* 3. 면접 세션 기록 및 복습 대시보드


* 면접 종료 시 전체 질문-답변 세션 데이터가 Supabase DB에 자동 저장.
* 마이페이지(대시보드)에서 날짜별 면접 기록 열람, 텍스트 스크립트 복사 및 Markdown 파일 다운로드.



---

4. 사용자 이용 흐름 (User Flow)

* 1단계 (모드 선택): [기본 면접 / 기술 면접 / 커스텀 질문 세트] 중 선택.
* 2단계 (질문 제시): 화면에 일본어 질문이 표시되며 브라우저 음성(TTS)으로 재생.
* 3단계 (음성 답변): 지원자가 일본어로 답변을 말하면 텍스트창에 실시간으로 자동 타이핑.
* 4단계 (다음 질문): 답변 완료 후 다음 질문으로 넘어가며 세션 진행 (5~10문항).
* 5단계 (결과 저장): 전체 질문-답변 로그가 Supabase에 저장되고 세션 리포트 확인.

---

5. 기대 효과

* 고정 비용 및 API 종속성 없는 완전한 독립 웹 서비스 운영.
* 일본어 스피킹 훈련과 텍스트 아카이빙을 동시에 진행하여 실전 면접 적응력 극대화.
* Vercel + Supabase 기반의 풀스택 포트폴리오로 활용 가능.
