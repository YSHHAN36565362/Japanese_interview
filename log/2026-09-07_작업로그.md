## 1. 문법 교정 모드 (GrammarPanel) 추가

면접 화면에 "문법 교정" 탭을 새로 만들어 달라는 요청 — 조사(が/を/に) 오용, 문체(반말/정중체)
혼용, 필러(간투사), STT 오인식(기술용어·장음), 반복 인식을 규칙 기반(정규식/사전)으로 잡아내고
왜 틀렸는지 한글 설명까지 붙인다. 기존 `lib/feedback.ts`와 동일하게 **LLM 호출 없음** 원칙을
그대로 따름(사용자가 규칙 기반을 명시적으로 선택).

- 신규: `lib/grammarCheck.ts`(핵심 로직), `features/interview/lib/grammarCheck.ts`(재노출),
  `features/interview/components/GrammarPanel.tsx`(UI)
- `GrammarIssue`에 `translation` 필드를 추가해 "好き = '좋아하다' — 이 뜻일 때는 항상 が를
  씁니다" 같은 한글 뜻 설명을 붙임
- `features/interview/constants.ts`(AUX_TABS에 'grammar' 추가), `InterviewRoom.tsx`(탭 연결),
  `useInterviewMachine.ts`(저장 시 `feedback_result`에 문법 이슈 건수 병합), 결과 페이지에
  "문법 교정 이슈 총합" 통계 카드 추가

## 4. "예전에 있던 기능들이 어디 갔냐" — 로컬이 origin보다 11커밋 뒤처져 있었음

사용자가 "소프트웨어/반도체 지원 직무 선택", "음성 사운드 조절" 같은 예전 기능이 안 보인다고
질문 — 조사해보니 **기능이 삭제된 게 아니라 로컬 main이 origin/main보다 11개 커밋 뒤처져
있었음**. `git log origin/main`에 로컬에 없는 커밋들이 있었고(`알고리즘 업데이트`,
`Merge origin/main: combine job-track/rate-pitch features with resume upload + follow-up
algorithm work` 등), diff로 보니 **61개 파일, 11,019줄**이 통째로 로컬에 없었음:

- 소프트웨어/반도체/기본 지원 직무 트랙 선택 (`lib/questionBank.ts`, `app/interview/page.tsx`)
- TTS 볼륨/속도/톤 조절 (`useSpeechSynthesis.ts`), 파형 표시(`VoiceWaveform.tsx`)
- .docx 이력서 업로드 + 파싱 + 맞춤 질문/꼬리질문 자동 생성 (`app/interview/resume`,
  `app/api/resume/parse`, `lib/resume/*`)
- STT 보정 사전 직접 관리 UI (`CustomTermManager.tsx`)

**처리**: 이번 세션에서 만든/고친 것(문법 교정 모드, 정리, 디자인 1차)을 `git stash push -u`로
안전하게 보관한 뒤, `git fetch` + `git merge origin/main`으로 fast-forward 병합(충돌 없음,
로컬 main이 origin의 순수 조상이었기 때문). 이후 `npm install`로 새 의존성(jszip,
fast-xml-parser 등) 설치.

- 스태시는 아직 저장소에 남아 있음: `stash@{0}: "pre-merge snapshot: grammar mode + cleanup
  + design work before pulling origin/main"`. 필요 없으면 `git stash drop`으로 지워도 됨
  (§1~§3 작업물은 이미 §5에서 새 코드베이스 위에 다시 적용됐으므로 내용 자체는 안전).

## 5. 병합된 코드베이스 위에 §1~§3 작업 재적용

원격 코드베이스가 로그인 플로우(`router.replace('/login')` 등)까지 포함해 완전히 다른
버전이라, "로그인/시작 로직은 건드리지 말고 그대로 두라"는 사용자 지시에 따라 인증 관련
변경은 재적용하지 않고, 아래만 다시 적용:

- 문법 교정 모드(§1) 전체를 새 `useInterviewMachine.ts`/`constants.ts`/`InterviewRoom.tsx`
  구조에 맞게 재연결
- 결과 페이지 `LikeButton` 제거, `RoomControls`/`InterviewStage` 중복 버튼 제거(§2)
- `RoomControls` 그룹+구분선, 로그인 카드 중앙 정렬(§3) — 단, 로그인 에러 메시지 한국어 폴백은
  "로직은 최신 커밋 그대로 두라"는 지시에 따라 되돌림(레이아웃 스타일만 유지)
- 확인: `장음 인식 안정성` 버그는 이 코드베이스엔 원래 없었음(`computeSessionScore`가 저장된
  컬럼이 아니라 텍스트에서 매번 다시 계산하는 방식이라 해당 버그 자체가 성립 안 함)

## 6. 사용자 시작 흐름 두 차례 조정 (§5 이후, §7 이전)

1. "마이페이지에서 고유번호 입력, 모드선택/면접은 그냥 되게" 요청 → 세션이 없으면 조용히
   익명 로그인 후 진행하도록 시도, 실패 시에만 `/login`으로 폴백
2. "그래도 로그인 화면이 뜬다" → 익명 로그인 실패 시의 `/login` 리다이렉트 폴백까지 완전히
   제거, 로컬 전용 id(`crypto.randomUUID()`)로 오프라인 게스트 진행하도록 변경(`/login`
   화면을 절대 보지 않게 함)

**이 두 변경은 §7 직전에 사용자가 "원격 최신 커밋 로직으로 되돌리라"고 명시적으로 요청해
전부 되돌렸습니다.** 현재 `app/interview/page.tsx`, `useInterviewMachine.ts`의 인증 체크는
origin/main 병합 시점 그대로(`router.replace('/login')`)입니다.

  `.btn-3d` 스타일로 교체

  어둡게 유지
